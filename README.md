# OperationsPortal

## Overview
OperationsPortal is a manufacturing operations system designed to manage items, BOMs, inventory, and multi‑site operations.  
This is a modern, clean rewrite of concepts I worked with in a real production environment.

---

## Current Phase  
**Phase 1 — Core Domain Modeling**

- Items  
- Units of Measure  
- BOM (Header + Lines)  
- Inventory  
- Locations  
- EF Core setup  
- Migrations  
- CRUD screens  

---

## Tech Stack
- ASP.NET Core  
- EF Core (Code‑First)  
- React + TypeScript  
- PostgreSQL  
- GitHub for version control
